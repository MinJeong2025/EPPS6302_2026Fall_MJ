The Wikipedia and World Bank reserve values differ for several countries. For example, China reports about $3.855 trillion on Wikipedia compared with $3.456 trillion from the World Bank, while India reports about $786 billion compared with $643 billion. One major reason is that the two sources represent different data vintages: the World Bank comparison uses 2024 observations, while Wikipedia reports country-specific dates, with many observations from 2025 or 2026. Differences may also reflect differences in reporting definitions and source updates.

3.3 When Is Web Scraping Appropriate?

Web scraping is appropriate when the required data are available on a public webpage but cannot be obtained through an accessible API or downloadable dataset. When a reliable API is available, it is generally preferable because it provides structured data and reduces problems caused by changes in webpage structure.

4. Data Plan: Employment Data

4.1 Data Source and Research Purpose

For my research on county-to-county commuting flows in Texas, I plan to use employment data from the U.S. Census Bureau’s County Business Patterns (CBP). County-level employment counts can represent job opportunities at commuting destinations. I would collect data for 2013 and 2020 to align with my commuting datasets. The official source provides geographic identifiers and annual employment statistics that can be linked to county-level commuting data.

4.2 Robots.txt and Terms of Service

Before accessing the data, I would review the Census Bureau website’s robots.txt file and applicable terms of service or API usage guidance. I would check whether the intended access path is permitted and follow any stated restrictions. Because an official API is available, I would use that interface rather than automatically scraping HTML pages. The exact permissions and current conditions should be verified before collection.

4.3 API Availability

The Census Bureau provides an API for County Business Patterns. I would request the employment variable and county geographic identifiers for Texas separately for each study year. Using the official API is preferable to scraping a webpage because the response is structured and the variables and geographic coverage can be specified. I would check the documentation for the correct year-specific endpoint and any API-key requirements before requesting data.

4.4 Data Volume, Rate Limiting, and Caching

The initial collection would cover Texas’s 254 counties in two years, or approximately 508 county-year records if every county is reported in both years. I would request only the variables and years needed, avoid repeated calls, and respect any documented usage limits. I would save the downloaded data locally in CSV or RDS format so that subsequent analysis can use cached copies rather than repeatedly contacting the API.

4.5 Detecting Changes in Data Structure

Changes to variable names, API endpoints, or response formats could interrupt data collection. I would check that the expected columns and county identifiers exist, inspect missing values and duplicate county-year combinations, and compare the number of returned records with expected coverage. If these checks fail, I would review the API documentation and revise the data retrieval code before analysis.
